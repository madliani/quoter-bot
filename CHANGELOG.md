## [0.2.0] - 2025-09-11

### Added

- `citaty`: a web scraping library for the
  [Цитаты известных личностей](https://ru.citaty.net/).
- `quotepark`: a web scraping library for the
  [QuotePark](https://quotepark.com/).
- `Upstash Redis`: a cloud storage for Redis.
- Periodical sending of the quotes.
- Translation of the bot UI into Russian and English.

### Changed

- The `LGPLv3` license was replaced by `SSPL`.

### Removed

- `russian_wikiquote`: a web scraping library for the
  [Russian Wikiquote](https://ru.wikiquote.org/).
- `wikiquote`: a web scraping library for the
  [Wikiquote](https://wikiquote.org/).

## [0.1.0] - 2025-03-04

### Added

  [Wikiquote](https://wikiquote.org/).
