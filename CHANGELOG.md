## [0.2.0] - 2025-09-11

### Added

- The `citaty` library: a web scraping library for scraping
  [Цитаты известных личностей](https://ru.citaty.net/).
- The `quotepark` library: a web scraping library for scraping
  [QuotePark](https://quotepark.com/).
- The `Upstash Redis`: a cloud storage for Redis.
- Periodic quote sending.
- Translation of the bot UI into Russian and English.

### Changed

- The `LGPLv3` license was replaced by the `SSPL` license.

### Removed

- The `russian_wikiquote` library: a web scraping library for scraping
  [Russian Wikiquote](https://ru.wikiquote.org/).
- The `wikiquote` library: a web scraping library for scraping
  [Wikiquote](https://wikiquote.org/).

## [0.1.0] - 2025-03-04

  [Wikiquote](https://wikiquote.org/).
